Elke vakterm in één zin, met de plek in het huis erbij.

<Woordenboek>

| Term | In gewone taal | In het huis |
| --- | --- | --- |
| 2FA / tweestapsverificatie | Inloggen met twee bewijzen: iets wat je weet én iets wat je hebt. Een code uit een app is 2FA, een passkey ook | Het tweede slot |
| Alias (e-mail) | Een wegwerpadres dat doorstuurt naar je echte adres | Een aparte brievenbus per afzender |
| Authenticator-app | App die elke halve minuut een nieuwe inlogcode maakt | De sleutel van het tweede slot |
| AVG | De Europese privacywet over omgaan met persoonsgegevens | De huisregels voor andermans sleutels |
| Back-up | Een kopie van je bestanden op een andere plek | De brandkast buiten de deur |
| Botnet | Een leger van gekaapte apparaten (vaak oude routers) dat samen aanvallen uitvoert | Jouw schuur als schuilplaats van een ander |
| Datalek | Gegevens die bij een bedrijf op straat komen te liggen | Inbraak bij de sleutelmaker |
| DDoS-aanval | Duizenden computers bezoeken tegelijk één site, zodat die voor echte bezoekers onbereikbaar wordt | Een steen door de ruit, geen inbraak |
| Deepfake | Met AI nagemaakte video, foto of stem van een echt persoon | Een inbreker met het gezicht van je buurman |
| Encryptie / versleuteling | Gegevens onleesbaar maken voor wie de sleutel niet heeft | Een kluis om je spullen |
| Extensie | Een uitbreiding voor je browser | Iemand die mag meekijken door je raam |
| Firmware | De ingebouwde software van een apparaat, zoals je router | Het binnenwerk van het slot |
| Hacktivist | Iemand die hackt uit politieke overtuiging, vaak in een groep en soms gestuurd door een land | De relschopper in de straat |
| Hardware key | Een fysiek sleuteltje dat je in je apparaat steekt of ertegen houdt: een passkey in metaal, en de sterkste vorm van 2FA | Een echte sleutel aan je sleutelbos |
| Herstelcodes | Eenmalige noodcodes om binnen te komen zonder telefoon | De reservesleutel bij de buren |
| Kwantumcomputer | Nieuw type computer dat bepaalde wiskundige sloten kan breken | De loper voor oude sloten |
| Malware | Verzamelnaam voor kwaadaardige software | Ongedierte in huis |
| Passkey | Inloggen met je toestel plus je vinger, gezicht of pincode: twee stappen in één handeling, dus een vorm van 2FA | De sleutel die niet te kopiëren is |
| Phishing | Nepbericht dat je laat klikken, inloggen of betalen | De babbeltruc aan de deur |
| Post-kwantumcryptografie | Nieuwe versleuteling die bestand is tegen kwantumcomputers | De nieuwe generatie sloten |
| Ransomware | Software die je bestanden gijzelt voor losgeld | Gijzeling van je inboedel |
| Router | Het kastje dat je huis met internet verbindt | Tuinhek en meterkast |
| Sim-swapping | Je telefoonnummer laten overzetten naar een oplichter | Iemand laat je post omleiden |
| Social engineering | Mensen manipuleren in plaats van systemen hacken | De inbreker die aanbelt in een net pak |
| Statelijke actor | Een land dat hackt: voor spionage, sabotage of beïnvloeding | De inbreker met een leger achter zich |
| Tracking | Volgen wat je online doet om een profiel op te bouwen | Meekijkers door het raam |
| Update | Reparatie van fouten in software | De timmerman die scheuren dicht |
| VPN | Een afgeschermde verbinding tussen jou en het internet | De overdekte gang naar buiten |
| Wachtwoordmanager | Programma dat al je wachtwoorden maakt en bewaart | De sleutelkluis |

</Woordenboek>
